# Varikuti Sree Charan Reddy — Portfolio

A high-performance single-page developer portfolio showcasing full-stack web engineering, Java backend systems, and responsive user experiences.

**Live Site:** https://myportfolio-blush-pi-72.vercel.app/

---

## 🛠 Tech Stack

- **Framework & Tooling:** React 19, Vite
- **Styling:** Tailwind CSS 4
- **Animations & Effects:** Framer Motion, AOS (Animate On Scroll), WebGL Fluid Simulation
- **Contact Service:** EmailJS (`@emailjs/browser`)
- **QR Code:** `react-qr-code`

---

## 🚀 Run Locally

Clone the repository and install dependencies:

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```

---

## ⚙️ Environment Variables

Create a `.env.local` file in the project root to configure the EmailJS contact form (optional; falls back to direct email if omitted):

```env
VITE_EMAILJS_SERVICE_ID=
VITE_EMAILJS_TEMPLATE_ID=
VITE_EMAILJS_PUBLIC_KEY=
```
